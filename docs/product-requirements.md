# 📋 Product Requirements Document (PRD)

# 🌌 Nova

> **A Life Operating System**

Version: 0.1

Status: Draft

Last Updated: August 2026

---

# 1. Overview

Nova is a **Life Operating System** that helps people manage every important aspect of their lives from one unified platform.

Instead of switching between multiple disconnected applications for tasks, health, finance, learning, goals, and personal growth, Nova provides one connected ecosystem where users can understand, organize, and improve their lives.

Nova is not designed to maximize productivity.

Nova is designed to maximize intentional growth.

---

# 2. Vision

Create the world's most thoughtful personal operating system that helps people become who they want to be.

---

# 3. Mission

Help people make meaningful progress every day by connecting all aspects of life into one intelligent platform.

---

# 4. Problem Statement

Modern life is fragmented.

A typical person may use:

- Google Tasks
- Google Calendar
- Samsung Reminders
- Google Keep
- Notion
- Splitwise
- Expense Tracker
- Habit Tracker
- Water Tracker
- Sleep Tracker
- Journal
- Kindle
- Duolingo

Each application solves one problem.

None provide a complete picture of a person's life.

This fragmentation creates:

- Forgotten goals
- Inconsistent habits
- Poor visibility into progress
- Information scattered across apps
- Decision fatigue
- Reduced motivation

Nova solves this by bringing everything together.

---

# 5. Goals

Nova aims to:

- Organize every important area of life
- Reduce app switching
- Help users build long-term habits
- Make progress visible
- Encourage intentional living
- Support continuous learning
- Promote self-care alongside productivity

---

# 6. Non Goals

Nova is NOT intended to become:

- A full accounting software
- A hospital health records system
- A replacement for Google Drive
- A social media platform
- A messaging application
- A document editor
- A note-taking application like Notion
- A project management platform like Jira

Nova integrates ideas from these products without replacing them entirely.

---

# 10. Key Differentiators

Unlike traditional productivity apps:

Nova provides complete life workspaces.

Instead of empty pages,

Nova provides thoughtfully designed Living Templates.

Users can:

- Customize
- Delete
- Duplicate
- Expand
- Build their own systems

Nova becomes increasingly personalized over time.

# 15. Design Philosophy

Nova should feel:

- Calm
- Minimal
- Intentional
- Friendly
- Intelligent
- Personal

Never:

- Stressful
- Corporate
- Overloaded
- Gamified for addiction

---

# 16. Product Philosophy

Nova is not trying to help users do more.

Nova is trying to help users become better.

Every feature should answer one question:

> "Does this genuinely help someone build a better life?"

If the answer is no,

it does not belong in Nova.
